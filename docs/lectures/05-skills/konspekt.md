# Konspekt — Wykład 05: Skills

## 01. Skills

Skąd agent wie, jak wykonać zadanie?

## 02. Tool vs Skill

Tool mówi agentowi, **co może zrobić**. Skill mówi agentowi, **jak ma to zrobić**.

## 03. Anatomia Skilla

Skill to katalog z plikiem `SKILL.md` — a jego najważniejszą linijką jest `description`: co robi i kiedy go użyć.

## 04. Progressive disclosure

Agent zna katalog Skills od początku, ale treść czyta dopiero wtedy, gdy jej potrzebuje: metadane → instrukcje → zasoby.

## 05. Skills a MCP

Tools, Resources, Prompts i Skills odpowiadają na różne pytania. MCP daje agentowi ręce, Skill daje przepis.

## 06. Skill w akcji — wejście do MiNI

**Demo — Tup Żak.** Skill `campus-entrance` prowadzi agenta przez narzędzia MCP i dialog z użytkownikiem: znajdź budynek → pobierz geometrię → ustal wejście → zaproponuj punkt → potwierdź i zapisz.

## 07. Następny wykład — Code Execution

Ile kosztuje lampka przez cały semestr? Gdy agent nie ma gotowego narzędzia — pisze i uruchamia własny kod.
