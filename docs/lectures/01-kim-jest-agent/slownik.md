# Słownik pojęć

- **agent** — byt programowy, który działa w imieniu użytkownika lub innego programu.
- **prompt systemowy** — ustawia programista aplikacji.
- **prompt użytkownika** — obejmuje konkretne instrukcje dla danego zadania.
- **kontekst** — informacja, którą model ma uwzględnić podczas generowania odpowiedzi.
- **transformer** — architektura.
- **LLM** — duży model językowy, często oparty na Transformerze.
