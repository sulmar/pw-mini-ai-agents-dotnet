# Konspekt — roadmap wykładu

## 01. Halucynacja

Wiarygodna forma nie oznacza prawdziwej treści — skoro AI się myli, po co nam właściwie AI?

**Demo — TUP Lab.** AI nie tylko odpowiada na pytania — może realizować cel i działać w rzeczywistym systemie.

## 02. Tytuł — Tworzenie agentów AI w .NET

Spróbujemy zrozumieć, jak projektować systemy, w których AI jest jednym z narzędzi.

## 03. Kim jest agent?

Agent otrzymuje cel, obserwuje sytuację, podejmuje decyzje i wykonuje działania.

## 04. Agent w środowisku

Agent działa w pętli: obserwuje środowisko → podejmuje decyzję → działa → obserwuje rezultat.

## 05. Historia LLM

Transformer → GPT → instruction following → ChatGPT → reasoning + tools stworzyły fundament współczesnych agentów.

## 06. LLM vs Agent

LLM generuje odpowiedź, a agent wykorzystuje model, aby realizować cel i podejmować działania.

## 07. Nowe narzędzie

Agent to nowe narzędzie w skrzynce inżyniera — nie powód, żeby wyrzucić pozostałe.

## 08. Inżynier i beton

Nie pytamy „jak użyć tutaj AI?”, lecz „która część problemu rzeczywiście wymaga AI?”.

## 09. TUP Żak — pojęcia

Na jednym przykładzie zobaczymy elementy, które przez cały semestr będziemy kolejno odkrywać i implementować.

## 10. Następny wykład

Skoro agent ma realizować nasze cele, to jak powiedzieć mu, czego od niego oczekujemy?
