# Tworzenie agentów AI w .NET

Wydział Matematyki i Nauk Informacyjnych Politechniki Warszawskiej

Materiały do wykładów i laboratoriów z projektowania i tworzenia systemów agentowych.

## Cel

Nie pytamy:

> **Jak użyć tutaj AI?**

Pytamy:

> **Która część problemu rzeczywiście wymaga AI?**

W trakcie kursu poznamy m.in. LLM, prompting, tool calling, MCP, Skills, embeddings, RAG, pamięć, systemy multi-agent oraz bezpieczeństwo i ewaluację agentów.

**.NET jest narzędziem. Uczymy się inżynierii systemów wykorzystujących agentów.**

## Tup Żak

Referencyjnym projektem rozwijanym podczas laboratoriów będzie **[Tup Żak](https://github.com/sulmar/campus-ai-assistant)** — agent pomagający studentom poruszać się po kampusie i korzystać z jego zasobów.

Studenci równolegle rozwijają własne projekty agentowe.
